# layouts/

Los layouts definen la estructura base que comparten todas las páginas.

## Archivo principal

- `MainLayout.astro`

## Qué hace

- carga el CSS global
- añade tipografías externas
- aplica el tema de la página
- inicializa scripts globales
- coloca el contenido de cada página dentro del documento principal
- define metadatos como título y descripción

## Importancia

Este archivo garantiza que todas las páginas del sitio compartan el mismo shell visual y comportamiento.
