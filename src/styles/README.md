# styles/

Esta carpeta guarda la capa visual global del proyecto.

## Archivo principal

- `globals.css`

## Qué controla

- tipografías
- colores base
- scrollbars
- estilos de cards
- estilos de botones
- layout global
- temas claro/oscuro
- utilidades visuales como `gradient-text` o `glass-card`

## Recomendación

Mantén los estilos reutilizables en este archivo. Evita poner CSS específico dentro de componentes si puede reutilizarse en toda la web.
